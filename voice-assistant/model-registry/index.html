    How to register a model

    A model is deployed only after its registry row exists with its sha256 and server-exact scores.

    1. Measure it with the features and runtime the cluster uses (for wake words, the server-exact pyopen-wakeword path; see lessons learned) and write the experiment document first.
    2. Store the file: a publishable file by version in the image or package registry; a licence-restricted file in the private repository agil/kivi-models with a model card, licence notes and SHA256SUMS (the repository README explains the layout).
    3. Add the row here: role, model, version, short sha256 of the served file, precision, where it runs, deployed (leave "No" until the owner approves), threshold and key settings, scores with a link to the experiment, licence, storage location.
    4. Only then open the GitOps change. After the rollout, update "Deployed? (since)" and keep the previous row's rollback version.
