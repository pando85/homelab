    Usage rules

    • Consent for voices. A person's voice is imported into the real-voice dataset (datasets 8, 9) only after that person agreed. Speakers are pseudonymous ids (spk01...) in every file and manifest; the mapping is the owner's, outside the repository. Household wake-stage audio (dataset 5) may be extracted as training negatives (dataset 10) under the same local-only rules.
    • Purpose limited to improving Kivi: speech-to-text, the hint list, aliases, custom sentences and the decision between the local and the LLM path. No other use.
    • Local analysis. Replay and statistics run on the workstation with scripts. Agents work from aggregates: counts, miss rates, category totals. Transcript text is never pasted into an AI session and never sent to a cloud or LLM API for analysis.
    • Samples for manual review are shown to the owner only.
    • Nothing private in git. No transcripts, samples, recordings or tokens in any repository, commit message, issue or pull request. Documents carry counts and shapes only.
    • Summary on use. When the data is used, the owner gets a summary of what was collected (period, number of utterances, kinds of sources) and what was done with it.
    • False wakes. Because the wake word is server-side, speech that did not address Kivi can be transcribed and stored. The household should know that the assistant's microphones feed this while the exception lasts.
    • Ending. The exception ends when the replay study is done, or earlier on the owner's decision: revert the commit, delete dataset 2, and decide whether to purge dataset 1 before it ages out.
